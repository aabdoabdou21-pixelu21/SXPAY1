# SXPay Gaming — لوحة تحكم حقيقية

هذه النسخة تستخدم Supabase كقاعدة بيانات + تسجيل دخول + تخزين صور.

## ما الذي تحصل عليه؟
- دخول للمشرف بالبريد وكلمة المرور.
- إضافة خبر من الهاتف أو الكمبيوتر.
- عنوان + تصنيف + وصف + محتوى + صورة.
- رفع الصورة إلى Storage.
- نشر/حفظ كمسودة.
- حذف الأخبار.
- الموقع العام يقرأ الأخبار المنشورة من قاعدة البيانات.
- PWA جاهزة للتثبيت.

## إعداد مرة واحدة
1. أنشئ مشروعًا مجانيًا في Supabase.
2. من SQL Editor شغّل `supabase.sql`.
3. من Authentication > Users أنشئ مستخدمًا للمشرف ببريدك وكلمة مرورك.
4. من Project Settings > API انسخ Project URL و anon/publishable key.
5. ضع القيم في `config.js`.
6. ارفع الملفات كلها إلى الاستضافة.
7. افتح `/admin.html` من هاتفك وسجّل الدخول.

## أمان مهم
لا تضع `service_role` key داخل ملفات الموقع. استخدم anon/publishable key فقط. صلاحيات RLS في SQL تمنع الزوار من إدارة الأخبار.

## الصور
يفضل WebP/JPG/PNG وبحجم معقول. يمكن لاحقًا إضافة ضغط تلقائي للصور.

## AdSense
أماكن الإعلانات موجودة في الواجهة. بعد قبول الموقع في AdSense، ضع كود Google الرسمي ووحدات الإعلانات المتجاوبة. قبول AdSense ليس مضمونًا ويعتمد على سياسات Google وجودة الموقع والمحتوى.

## ملاحظة
هذه لوحة حقيقية متصلة بقاعدة بيانات سحابية، لكنها تحتاج بيانات مشروع Supabase الخاصة بك قبل أن تعمل؛ لا أضع مفاتيح حسابك داخل المشروع.
